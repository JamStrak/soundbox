# 开放素材来源核验

核验日期：2026-09-30。适用版本：`catalog_manifest.json` version 1。本文记录本次真正完成来源、原包和逐文件验证的目录；动态搜索更多网站与后续候选不混入已接入统计。

## 已接入目录的证据与范围

新增 **28 个固定 CC0 素材包、2,278 条独立音频**，来自 Kenney 和 OpenGameArt 上的 11 组作者/工作室。原有 Interface / Impact / Digital 三套 Kenney 共 292 条保持原清单，不在新增清单重复。每条声音保留作者、作品页面、CC0 许可链接和精确原包成员路径。

实际格式为 **1,058 条原始 WAV**（990 PCM 16-bit、61 PCM 24-bit、7 float 32-bit）和 **1,220 条 OGG Vorbis**。OGG 是原作者提供的有损文件；“原始文件”指原包里的内容，不是音质分级。目录均可完整解码；名称/标签依据作者目录，未知项保持中性名称，不推测具体声音用途。仍需要用户试听判断是否适合具体游戏。

所有条目均已完整执行 FFprobe 和 FFmpeg 解码，最长 148.259410 秒，最大单条 26,153,138 字节；2,278 条逐文件 SHA-256 均不同。排除包内 Preview 演示混音、隐藏资源、非音频文档；标题与标签来自具体文件名/子目录加少量用途分类，不把整包所有材料词灌入每条标签。

无法从文件名确定用途时使用“杂项音效”中性标题，不用整包名称补足，以免把同包的法术、机械等主题错误赋给杂项声音。`misc_01` 不因 RPG 包包含法术而匹配 magic；`sfx100v2_air_01` 标为“空气”；桌游 `card-fan1` 按纸牌语境标为“扇牌”，不标为风扇。相关实际目录回归收录在 `tests/test_catalog_manifest.py`。

## 可重复维护

唯一维护脚本是 `tools/build_catalog_manifest.py`。在工程根目录执行 `python tools/build_catalog_manifest.py` 可重建全部固定目录；`--pack <固定包ID>` 可只更新已知包并保留其余条目，`--refresh` 对所选固定包重新联网下载。没有自由 URL 参数，也没有用户输入驱动的运行时抓站接口。重建前需维护者核实新增作者页面的许可与下载资格，并在脚本 SEEDS 显式加入。

脚本保留 HTTPS / TLS 验证，只访问 `kenney.nl` 与 `opengameart.org` 的允许路径；下载跳转也校验主机与路径。限制单 ZIP 160 MiB、单条 50 MiB、解包总量 1 GiB、最多 10,000 个成员，拒绝路径逃逸、符号链接、加密项和重复成员路径。音频必须在 10 分钟内、含有效音轨、能够完整解码。临时媒体放在 Windows 临时目录 `soundbox-catalog-build`，工程 `data/` 未参与构建，也不把媒体纳入 Git。

清单保存原包和每条媒体的 SHA-256、精确字节数及测得的时长、编码、采样率和声道数；额外记录许可页面 SHA-256 作为此次网页版本的证据。维护缓存须同时匹配原包 URL 和已记录哈希才复用。若运行时原包已被作者更新，应停止使用不匹配的版本，待维护者重建清单后再提供下载。

本次构建和核查结果：28 包 / 2,278 条全部完整解码成功；逐条重新读取 ZIP 验证文件哈希、大小、唯一目录 ID、时长与音轨参数通过；7 种非法来源 URL、5 种不安全 ZIP 成员的负向验证通过，28 个真实原包再次通过路径校验；`python -m py_compile tools/build_catalog_manifest.py` 通过。搜索、试听缓存、保存素材库和真实界面验证见本轮验收记录。

目录元数据与标题召回回归：`python -m pytest tests/test_catalog_manifest.py -q`，4 项通过。标题和标签修正复用原文件哈希和音轨元数据，没有重新下载媒体或改变原音频。

## 继续扩充的已核实候选

以下是本次找到的更多开放作者来源，**尚未加入上述 2,278 条统计**，不表示已经能够在声匣逐条试听。

- [Signature Sounds 总库说明](https://signaturesounds.org/the-signature-soundbank)：作者声明 150+ 包、80GB+ WAV 与 CC0；付费全库支持作者，独立免费包仍可用。已核实 [Kitchen Foley](https://signaturesounds.org/store/p/kitchen-foley) 5MB 与 [Old Wooden Door Foley](https://signaturesounds.org/store/p/old-wooden-door-foley) 4MB 页面均明确 CC0，另有 [Footsteps in Snow](https://signaturesounds.org/store/p/footsteps-in-snow-sound-effects-free-download-cc0-wav-sample-pack-) 8 条 WAV、75MB。当前网页显示 Squarespace 的零元 Purchase 领取流程，没有匿名固定 ZIP 直链；适合用户领取后导入，或取得作者提供的稳定公开链接后新增专门适配器，不逆向隐藏接口。
- [StillNorthMedia 中世纪武器碰撞](https://opengameart.org/content/medieval-sound-effects-weapon-impacts)：作者作品页明确 CC0 和免费使用声明，公开文件是两个 `.7z` 分卷包，现有安全缓存只处理 ZIP，留待受限 7z 读取支持后独立核验。
- [42 Snow and Gravel Footsteps](https://opengameart.org/content/42-snow-and-gravel-footsteps)：作品页写明取得 Corsica_S 的 CC0 再发布许可，公开包为 7z / FLAC，同上暂未接入。
- [CoMiGo Bleeps and Bloops](https://comigo.itch.io/bleeps-n-bloops)：作者明确 CC0、命名清晰的 WAV、2.3MB ZIP。itch 下载按钮走领取/临时链接流程；不能把站点搜索页当作无需密钥的公共音频 API。后续可加入稳定作者托管地址，或给用户原作者领取入口。

不得将“免费给游戏使用”与“允许声匣作为搜索音效原文件的来源”混为一谈。商业音效库的赠送包须逐份核实许可；不因为网页写免费就自动进入固定开放目录。
